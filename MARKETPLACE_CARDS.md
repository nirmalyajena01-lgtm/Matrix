# MATRIX Marketplace Assets

## 01 — Emergency Reporting Engine
**Buyer:** existing campus apps  
**Ask:** ₹1.5–2 Cr FED Coins  
**What they buy:** SOS, categories, GPS, evidence, anonymous reporting, AI-assisted priority, incident IDs and status API.  
**Integration:** REST + React widget.  
**Demo:** create incident → receive priority → incident ID.  
**Boundary:** no responder dispatch or analytics dependency.

## 02 — Responder Command Center
**Buyer:** security / authority teams  
**Ask:** ₹2–3 Cr FED Coins  
**What they buy:** priority queue, live map, responder allocation, ETA, SLA and broadcast alerts.  
**Integration:** REST + inbound incident API + status callbacks.  
**Demo:** receive INC-1042 → assign best responder → responding → resolved.  
**Boundary:** no student identity store and no analytics database dependency.

## 03 — Campus Safety Intelligence
**Buyer:** university administration  
**Ask:** ₹2–3 Cr FED Coins  
**What they buy:** KPI dashboard, hotspots, category trends, peak hours, SLA analytics and prevention insights.  
**Integration:** normalized events API.  
**Demo:** ingest events → heatmap/hotspots → SLA analysis → prevention recommendation.  
**Boundary:** analytics consumes events, never operationally dispatches responders.
